# Getting Started

Nested MDX file: `src/guide/getting-started.mdx` routes to
**/guide/getting-started** — the same folder-to-URL mapping as `.deshi`.

## Steps

1. Drop a `.mdx` file anywhere under `src/`
2. Import components from `src/components`
3. Run `vite build` — the page is statically generated

> MDX files share the same layouts, scope analysis and SSG pipeline as `.deshi`.

See the [MDX guide](/guide) or a [dynamic page](/guide/hello).
